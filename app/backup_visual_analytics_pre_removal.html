AMR Resistance Classes (Full 9-Phenotype Spectrum)

Active class glows dynamically upon prediction
CLASS 1
β-Lactams
Target: PBPs / Peptidoglycan Cell Wall
Enzymatic hydrolysis of β-lactam ring via nucleophilic Ser70 or zinc-coordinated catalytic water.
Penicillins, Cephalosporins, Carbapenems, Monobactams
CLASS 2
Colistin / Polymyxins
Target: Outer Membrane LPS / Lipid A
Phosphoethanolamine transferase (MCR) neutralizes negative charge, repelling cationic polymyxins.
Colistin (Polymyxin E), Polymyxin B (Last-resort drugs)
CLASS 3
Aminoglycosides
Target: 30S Ribosomal Decoding A-Site
Enzymatic modification (acetylation AAC, phosphorylation APH, adenylation ANT) abolishes ribosome binding.
Gentamicin, Tobramycin, Amikacin, Kanamycin
CLASS 4
Fluoroquinolones
Target: DNA Gyrase (GyrA) / Topo IV (ParC)
Target mutation at QRDR or pentapeptide repeat protection (Qnr) shields DNA replication forks.
Ciprofloxacin, Levofloxacin, Moxifloxacin
CLASS 5
Tetracyclines
Target: 30S Ribosome A-Site tRNA Binding
Active efflux via MFS pumps (TetA) or GTPase ribosomal protection proteins (TetM/TetW).
Tetracycline, Doxycycline, Minocycline, Tigecycline
CLASS 6
Macrolides (MLSB)
Target: 50S Ribosome 23S rRNA Exit Tunnel
Adenine N6-dimethylation by Erm methyltransferases creates steric hindrance at peptide exit tunnel.
Erythromycin, Azithromycin, Clindamycin
CLASS 7
Glycopeptides
Target: Peptidoglycan D-Ala-D-Ala Terminus
Synthesis of modified cell-wall precursors (D-Ala-D-Lac via VanA/VanB), reducing drug affinity 1,000-fold.
Vancomycin, Teicoplanin (VRE pathogens)
CLASS 8
Other AMR Determinants
Multi-Mechanism Heterogeneous Cluster
💊 Phenicols (catA)
🧬 Rifamycins (arr)
🔬 Trimethoprim (dfr)
⚡ Sulfonamides (sul)
Chloramphenicol, Rifampin, Trimethoprim, Co-trimoxazole
CLASS 9
Non-AMR Control
Target: Physiological Cellular Metabolism
Non-resistant bacterial housekeeping protein (polymerases, flagella, ATP synthases, standard kinases).
Negative Control baseline (Prevents false clinical positives)
